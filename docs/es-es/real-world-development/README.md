Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y una lista de tareas compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar su comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Situación

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. La lista de tareas de tu equipo ya está registrada como incidencias de GitHub, listas para que las elijas. Incluye trabajo de funcionalidades, como el filtrado y la paginación, además de mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza la situación compartida de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente agéntico en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, aptitudes, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia entre modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
